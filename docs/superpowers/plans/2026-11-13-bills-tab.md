# แท็บ "บิล" แทน "จัดก๊วน" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** เมนูล่างของเว็บจริงมีแท็บ "บิล" (แทน "จัดก๊วน") ที่พาไปหน้ารวมบิลแบบใหม่: ผู้จัดเห็นใครค้าง + จ่ายบิลของตัวเองได้ ผู้เล่นเห็นและจ่ายบิลของตัวเอง โดย QR โชว์เลยที่บิลแรกที่ต้องจ่าย

**Architecture:** หน้า `billing.html` เดิมไม่มี `bill`/`manage` ใน URL ให้เป็น "หน้ารวม" (home): เรียกรายการบิลผู้จัด (ถ้าเป็นผู้จัด) กับ `/api/member?action=bills` (ถ้าล็อกอิน LINE ผูกชื่อแล้ว) แล้ววาดสองส่วน "ของฉัน" + "ภาพรวม" ฟังก์ชันคำนวณ (จัดกลุ่มคนค้าง, ข้อความทวง) แยกเป็นโมดูลบริสุทธิ์ทดสอบด้วย node ได้ logic จ่าย/สลิป/อนุมัติเดิมใน `public/billing.js` ไม่แตะ

**Tech Stack:** Cloudflare Worker + D1, vanilla JS/CSS, `node --test`

**Spec:** `docs/superpowers/specs/2026-11-13-bills-tab-design.md`

## Global Constraints
- ข้อความแสดงผลเป็นภาษาไทย; escape ก่อนใส่ `innerHTML` (helper `escape()` ใน `billing.js`)
- จำนวนเงินเป็น**สตางค์**ทุกที่ (`payer.amount`); แสดงด้วย `money()` เดิม
- ห้ามเปลี่ยนสถานะการจ่ายอัตโนมัติ; ห้ามให้ผู้เล่นเห็นชื่อ/ยอด/ผล AI ของคนอื่น
- ก๊วนเลือกด้วย dropdown แบบเดิม (ไม่ใช้ปุ่มสลับ Sena|88) และอ่านจาก `?club=`
- เมนูล่าง: จองคิว / บิล / Cup / อันดับ (+ รายชื่อซ่อนเหมือนเดิม); พื้นเขียวเข้ม แท็บที่เลือก = เขียวมะนาว (ใช้ `public/next-nav.css` เดิม)
- ไม่ลบ `#session` ใน `court.html` (`app.js` อ้าง id) ซ่อนแท็บด้วย `hidden` เท่านั้น
- ไฟล์เทสใหม่ต้องเพิ่มใน script `test` ของ `package.json`; ไฟล์ JS ใหม่ใน `public/` ต้องเพิ่ม `node --check` ใน script `build`
- ก่อน commit รัน `npm run format`; push ได้ที่ branch `claude/happy-goodall-x8fbjb` เท่านั้น merge เข้า `main` เมื่อเจ้าของโปรเจกต์สั่ง

## Review Focus
- ผู้เล่นเรียกรายการบิลของผู้จัด (`GET /api/billing` ไม่มี `bill`) ต้องได้ 401 ไม่หลุดรายชื่อคนอื่น (เทสใน Task 1)
- `billView` ของผู้เล่น (มี token) ต้องไม่มี `payers` ของคนอื่นเพิ่มขึ้นหลังแก้ `summary` (Task 1)
- คนที่ค้างด้วยชื่อเดียวกันในสองบิลต้องรวมเป็นแถวเดียว ยอดรวมถูก (Task 2)
- สถานะ `review` นับเป็นค้างแต่ติดป้าย "รอตรวจสลิป"; `paid` ไม่นับ (Task 2)
- บิลที่ยกเลิกต้องไม่ถูกนับเป็นค้างทั้งใน "ใครยังค้าง" และยอดรวม (Task 2)
- ผู้เล่นที่ไม่มีบิลค้าง / ยังไม่ผูกชื่อ / ผู้จัดที่เข้าด้วย `ADMIN_KEY` อย่างเดียว ต้องเห็นข้อความที่เข้าใจได้ ไม่ใช่หน้าว่าง (Task 5)
