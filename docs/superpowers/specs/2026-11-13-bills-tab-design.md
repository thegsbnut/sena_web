# แท็บ "บิล" แทนแท็บ "จัดก๊วน" บนเว็บจริง — ดีไซน์

สถานะ: **รอเจ้าของโปรเจกต์อนุมัติ** (ยังไม่ลงมือสร้าง)

## เป้าหมาย / ที่มา
- ตัดแท็บ "จัดก๊วน" ออกจากเมนูล่างก่อน แล้วใส่แท็บ "บิล" แทน เป็นที่เดียวสำหรับจัดการและจ่ายบิล
- **ผู้จัด:** เปิดมาแล้วเห็นทันทีว่า "ใครยังค้าง" + ถ้าตัวเองมีชื่ออยู่ในบิลก็จ่ายได้ในหน้าเดียวกัน
- **ผู้เล่น:** เห็นและจ่ายบิลของตัวเอง เหมือนหน้าที่ badbot ส่งเข้ามา

## ไม่ทำ (non-goals)
- ไม่แตะ logic เดิมใน `public/billing.js` (สลิป, QR, อนุมัติ, AI ตรวจสลิป) และไม่เปลี่ยนสถานะการจ่ายอัตโนมัติ
- ไม่ให้ผู้เล่นเห็นผล AI สลิปหรือบิลของคนอื่น
- ไม่ลบโค้ดแท็บจัดก๊วน (ซ่อนจากเมนูเท่านั้น กลับมาได้)
- ไม่ส่งข้อความทวงเข้ากลุ่ม LINE เอง

## วิธีทำที่เลือก (ทาง C)
ทางที่พิจารณา: (A) iframe หน้าบิลเดิมในแท็บ — เร็วแต่ซ้อนแถบ/เลื่อนซ้อน; (B) เขียนใหม่เป็นส่วนของหน้าหลัก — เสี่ยง ต้องรื้อ `billing.js` 830 บรรทัด; **(C) แท็บ "บิล" พาไป `billing.html` ที่ออกแบบใหม่ + แถบเมนูล่างตัวเดียวกัน** — logic เดิมคงไว้ กลับของเดิมง่าย

## หน้าตา
**ผู้จัด** (บนลงล่าง)
1. **ของฉัน** — บิลที่ชื่อตัวเองค้างอยู่: บิลแรกที่ต้องจ่าย **โชว์ QR พร้อมเพย์เลย** (เรียก `qr` ของบิลเดียว) + ปุ่ม "บันทึกลงรูปภาพ" ใต้ QR → ขั้น 2 "แนบสลิป" → ลิงก์ "จ่ายเงินสดแทน"; บิลถัดไปพับเป็นปุ่ม "จ่ายด้วย QR" กดแล้วขยายทีละใบ; ไม่มีเลขพร้อมเพย์ที่ใช้ได้ = ไม่มี QR แสดงช่องทางโอนเป็นข้อความเหมือนเดิม (ใช้ action เดิมทั้งหมด) · ไม่มีค้าง = "ไม่มีบิลค้าง 🎉" · ชื่อพับประวัติที่จ่ายแล้วไว้ด้านล่าง
2. **ภาพรวม** — การ์ดเขียวเข้ม "ค้างรวม N บาท · X คน" + ป้าย "🤖 สลิปรอตรวจ" (เดิม)
3. **ใครยังค้าง** — จัดกลุ่มตามคน (ยอดรวม, ค้างกี่บิล, รอตรวจสลิป) + ปุ่ม "ทวง" คัดลอกรายชื่อไปวางใน LINE
4. **บิลแยกตามวัน** — แถบความคืบหน้า จ่ายแล้ว x/y เปิดเข้าบิลเดิมได้; กลุ่ม "จ่ายครบ / ยกเลิก" พับไว้
5. **ตัวเลือกก๊วน/สนามใช้แบบเดิม** (กล่อง "เลือกก๊วน / สนาม" แบบ dropdown เหมือนหน้าหลัก ไม่ใช้ปุ่มสลับ Sena|88) เพื่อรองรับสนามที่เพิ่มในอนาคต · ตั้งพร้อมเพย์เริ่มต้น, ตรวจแท็ก LINE ย้ายไปเมนูเล็ก (⋯)

**ผู้เล่น** — เฉพาะ "ของฉัน" (ข้อ 1) ผ่าน `/api/member/bills` ที่มีอยู่

ธีม: เขียวเข้ม/เขียวมะนาวตามเว็บจริง; แถบเมนูล่างเหมือนหน้าหลัก แท็บ "บิล" ขึ้นสีมะนาว

## ข้อจำกัด / การตัดสินใจของผม (ตรวจได้)
- "ของฉัน" ของผู้จัดระบุตัวตนจากบัญชี LINE ที่ผูกกับชื่อผู้เล่น (`member.js`) ถ้าผู้จัดเข้าด้วย `ADMIN_KEY` อย่างเดียวไม่ได้ล็อกอิน LINE จะแสดงปุ่ม "เข้าสู่ระบบ LINE เพื่อดูบิลของคุณ" แทน — *การตัดสินใจของผม*
- "ใครยังค้าง" ต้องเพิ่มข้อมูลรายคนใน `/api/billing` (ตอนนี้ `summary()` ส่งแค่ยอดรวมต่อบิล) เฉพาะเมื่อเป็นผู้จัด ไม่ใส่ชื่อ/ยอดของคนอื่นในมุมมองผู้เล่น — *การตัดสินใจของผม*
- แท็บ "จัดก๊วน" ซ่อนด้วย `hidden` ใน `public/court.html` ไม่ลบ `#session` เพราะ `app.js` อ้างอิง id เดิม
- ปุ่ม "บิลค้าง" ในหน้าจองคิวชี้ไปหน้าใหม่เหมือนเดิม
- เพิ่ม/ปรับเทส (`test-billing.mjs`) และ `package.json` ถ้ามีไฟล์เทสใหม่

## ที่เหลือให้ผู้สร้างตัดสิน
ขนาดตัวอักษร/ระยะห่างรายละเอียด, ข้อความตอนไม่มีบิล, ลำดับในกลุ่ม "ใครยังค้าง" (เรียงตามยอดมากไปน้อยเป็นค่าเริ่มต้น)
