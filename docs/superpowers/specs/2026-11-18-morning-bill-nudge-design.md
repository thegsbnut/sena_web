# ตามบิลตอนเช้าเมื่อมีคนพิมพ์ในกลุ่ม (ไม่ใช้ Push)

## เป้าหมาย
ทุกวัน ข้อความตัวอักษรแรกในกลุ่ม LINE ที่ผูกกับก๊วน (หลัง 06:00 เวลาไทย) ทำให้ Badbot ตามบิลค้างให้ 1 ครั้งต่อกลุ่มต่อวัน
ตอบด้วย reply token ของข้อความนั้น (ฟรี) ไม่ใช้ Push API

## ไม่ใช่เป้าหมาย
- ไม่ push เอง ไม่ใช้ cron ส่งข้อความ
- ไม่นับสติกเกอร์/รูป/คำสั่ง Badbot
- ไม่ตอบ "ไม่มีบิลค้าง"

## Approaches
- **A (เลือก):** ข้อความธรรมดาเท่านั้นเป็นตัวปลุก; โค้ดแยกโมดูลเล็ก เรียกจาก `lineWebhook` ไม่แตะ `replyToGroupCommand`
  คำสั่ง Badbot ข้ามไปรอข้อความธรรมดาถัดไป ยกเว้น `badbot bill` ที่นับว่าตามแล้ว
- B (ไม่เลือก): ต่อท้ายคำตอบของคำสั่ง — reply token ใช้ครั้งเดียว/สูงสุด 5 ข้อความ และข้อความตามที่ LINE ปฏิเสธจะลากคำตอบของคำสั่งพังไปด้วย

## พฤติกรรม
- วันของการตาม = วันที่ไทยของเวลาข้อความ (`event.timestamp`); ข้อความที่ส่งก่อน 06:00 เวลาไทยไม่ปลุกบอท
- กลุ่มผูกก๊วนไหน: อ่านจาก `line_groups` (แถวต่อก๊วน group_id เดียวกันได้)
  สองก๊วน → scope `all`; ก๊วนเดียว → scope ก๊วนนั้น; ไม่ผูก → ไม่ทำอะไร
- กัน race: ตาราง `line_daily_nudges (group_id, day, claimed_at)` `INSERT OR IGNORE`; แถวที่ชนแล้ว = ตามแล้ว
- ลำดับ: claim → สร้างข้อความด้วย `billingLineMessages` (แท็กคนค้างเหมือน `badbot bill`) → ถ้าไม่มีบิลค้าง **ปล่อย claim** แล้วเงียบ → ส่ง reply → ถ้าส่งไม่สำเร็จ **ปล่อย claim** ให้ข้อความถัดไปลองใหม่
  (ไม่มีบิลค้าง = ปล่อย claim จึงเช็กซ้ำทุกข้อความ; ยอมรับเพราะเป็นแค่อ่าน D1 — ถ้ากังวลให้เก็บ marker "ไม่มีบิล" ไว้ 1 ชม. เป็นงานต่อไป)
- `badbot bill` (ทุก scope) / notice ชนิด `bill` (การ์ดบิลหลังสร้างบิลใน LIFF) ที่ตอบสำเร็จ → บันทึกว่าวันนี้ตามแล้ว โดย `replyToGroupCommand` คืนค่า `'bill'` เมื่อตอบบิลสำเร็จ (แก้เล็กน้อยที่ท้ายฟังก์ชัน) แล้ว `lineWebhook` เป็นคนบันทึก
- ทำงานใน `ctx.waitUntil` เดิม; ไม่มี context (เทส) → await
- ถ้า `LINE_MEMBER_AUTH_ENABLED`/`LINE_LIFF_ID` ไม่พร้อม `billingLineMessages` คืน null → ไม่ทำอะไร

## ข้อกำหนดอื่น
- ตารางสร้าง lazy ด้วย `CREATE TABLE IF NOT EXISTS`; ลบแถวเก่า > 7 วันทุกครั้งที่ claim
- เทสใหม่ต้องใส่ใน script `test` ของ `package.json`; อัปเดต `BADBOT-REPLY.md` ท้ายไฟล์ และ `HANDOFF.md`
